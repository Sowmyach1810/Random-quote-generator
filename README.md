# Random Quote Generator

A simple and interactive web application that displays random inspirational quotes with their authors.

## Features
- Displays random motivational quotes
- Includes 10 inspirational quotes
- Shows quote author names
- New Quote button to generate another quote
- Share Quote button to share or copy the quote
- Prevents the same quote from appearing consecutively
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Open the Random Quote Generator.
2. Read the displayed quote.
3. Click the **New Quote** button to generate another quote.
4. Click **Share Quote** to share or copy the quote.
